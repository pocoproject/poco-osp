WebEvent Sample

The server accepts the WebSocket of this page only from a browser that has logged in to the web session that the setting osp.web.event.session names. The login below checks the user name and the password with the authentication service of the server, for example the one of the SimpleAuthService sample, which knows the users admin and user with the passwords of the settings adminPassword and userPassword. It logs the browser in to the web session sample.webevent, which the configuration of the BundleServer sample names in osp.web.event.session, and reloads this page.
